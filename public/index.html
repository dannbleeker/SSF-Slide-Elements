SSF Slide Elements

A library of ready-made slide elements for PowerPoint. Browse the collection in the task pane, click an element, and it lands on the slide you are on with every font, colour and placement intact.

Not yet released. What can be installed today is the pane itself — it opens, shows which build it is and checks your PowerPoint — and it inserts nothing yet.

Get the add-in

Download manifest-prod.xml from the latest release once there is one, or take the file on main, which is the same pointer, and sideload it in PowerPoint.

Source and progress: github.com/dannbleeker/SSF-Slide-Elements.
